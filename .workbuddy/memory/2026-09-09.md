## ⚠ 沙箱坑：git update-ref 静默失效（remote-tracking ref 写不进去）
- 现象：`gh repo create --push` 后远端确实有 `main`（`git ls-remote` 可见、提交一致），但本地 `git status -sb` 显示 `## main...origin/main [gone]`、`git branch -vv` 显示 `[origin/main: gone]`。
- 根因：`git update-ref` / `git fetch` 写 `refs/remotes/origin/main` **返回 exit 0 却不落盘**（沙箱拦截），`.git/refs/remotes/` 始终为空、无 packed-refs。
- 解法：绕过 git 命令，**直接写松散 ref 文件**：
  `mkdir -p .git/refs/remotes/origin && printf '%s\n' <40位sha> > .git/refs/remotes/origin/main`
  文件落盘后 `git show-ref` 立刻识别，tracking 恢复正常。
- 教训：`git update-ref` 返回 0 ≠ 写成功；本沙箱下遇到 ref 异常先看 `.git/refs/` 实际文件，必要时手工写。（同类：安全删除垫片会拦 `fs.rm`，见用户级记忆。）
