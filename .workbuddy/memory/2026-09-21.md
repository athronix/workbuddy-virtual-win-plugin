### 20:0x #2 隧道守护进程固化 —— 修复致命入口自杀 bug + 自愈验证
- **真因**：`delivery/tunnel-daemon.mjs` 入口守卫 `runDaemon(...).then(code => process.exit(code))` 在 `tunnel.start()` ready 后**立即 `process.exit(0)`**，把刚建好的隧道杀掉 → 这才是「守护进程替代不了 ad-hoc ssh」的真实原因。
- **修复**：入口成功路径**不再 exit**，仅 SIGINT/SIGTERM → `shutdown()`（清理 pidfile/state）；加常驻 `keepAlive` timer 防事件循环空转退出。
- **自愈三关实证**：① 持久存活（pid 64997，间隔 16s 两次 `/health` HTTP 200）；② SSH 传输层退避重连（`oh-tunnel.mjs`）；③ 进程级崩溃恢复（`kill -9` → 陈旧 pidfile/state；重拉时 L117-122 幂等守卫 `isAlive` 判死 → `rmSync` 陈旧 → 干净重启 **pid 4791**、state RUNNING、HTTP 200）。
- **④ 进程级自动重启兜底** = HOURLY watchdog `aaa87da4`（ACTIVE）。
- **纠正**：`tunnel-daemon.mjs` **无 `--daemon` 开关**；入口直接跑即常驻。
