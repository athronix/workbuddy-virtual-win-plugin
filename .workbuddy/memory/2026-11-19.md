### 本轮新暴露并修完的三个问题（P9~P11，v2.5.1）

**P9（P0）`-File` 执行 oneclick 必挂 —— 编码契约双向**
源文件必须 UTF-8 **无 BOM**（`irm|iex`/`Create` 把 BOM 当首字符 ⇒ param 块脱离参数区）；但 `powershell -File` 在 PS 5.1 **不认 UTF-8 声明**，按系统 ANSI(CP936) 解码无 BOM 文件 ⇒ 中文注释变乱码 ⇒ `?` 打断引号 ⇒ `ParserError`，**一行未执行**。修：源无 BOM + 落盘副本统一转 UTF-8 with BOM（四条路径全覆盖）。

**P10 第三个 node 运行时 store**
跑过 nvm-windows 的机器有**三个** store：`C:\nodejs`、`%LOCALAPPDATA%\Author Software\nvm`、**`%LOCALAPPDATA%\nodejs`（zip 装的用户级副本，漏了）**。判据加 `LOCAL_NODEJS_DIR`。

**P11 僵尸 node.exe 镜像永不可删**
pid 6048 = `codebuddy mcp remove agent-desktop`（部署脚本自己拉起、未回收）。它是**僵尸**：`HasExited=True` 但父 `cmd.exe`(session 0) 不关句柄 ⇒ `Terminate` rc=2、`taskkill`「没有运行实例」；父进程同样杀不掉。对策：第三轮 `EvictLocked` 把死镜像**改名移出**到 `C:\ProgramData\WinVMStale` + 登记 `PendingFileRenameOperations`（开机删），目录即可回收 ⇒ 不重启 VM 也能 PASS。

### 三条通用教训（写进门禁注释）
1. 「源文件编码」与「执行副本编码」是两个独立契约，按**执行路径**分别满足。
2. 「清完还残留」先怀疑**清单不全**，再怀疑删不掉。
3. Windows「访问被拒绝」有四种成因（ACL/句柄/僵尸/只读），**先用 Restart Manager 拿持有者名单再动手**；`rmdir /s /q` 会把它变成无信息的静默失败。Restart Manager 是唯一 in-box 的「谁占着这个文件」查询手段。

## 18:0x~18:2x 三个直觉被实测否掉（用户提问驱动的纠偏）

**三问的实测答案（VM 172.16.100.2，均为真机）**：

1. **短路方案作废** —— 用户裁定成立。技能目标是新用户首装，`MANIFEST total-sha256`
   短路只利好开发者反复重跑，对真实用户收益为零。已在报告 §7 与 HTML 里标为「已否决」，别再加回来。
2. **tar+scp 不是瓶颈**：tar 3.9MB **0.13~0.35s**（3 次）、scp 同体积 **1.8~2.6s**（5 次含建连）
   ⇒ 合计约 **3s**，占 `[VM] 94.8s` 的 3%。预打包 tar 只省 0.3s，**不值得**。
   `[VM]` 的大头是远端 install-vm 六段（PS 冷启 + 计划任务往返 + 自检轮询）。
3. **删除假设整体反了**：`Remove-Item -Recurse -Force` 删真实目录（489f/7.3MB）**0.75~1.1s**；
   **丢回收站反而 7.5s，慢 10 倍**（Shell.Application InvokeVerb）。25s 是**段级**口径。
   耗时看**文件数不看体积**：489f≈1s、5000f≈9.5s。

**顺带挖到的真 bug（值得单独立项）**：服务在跑时 3 个进程把 `C:\WinVMBridge` 当 cwd
（PID 13020 vm-service `cli.js --port 18443`、PID 2632 `ps-bridge.ps1`、PID 12508 `start-hidden.ps1`），
此时 `Remove-Item -Recurse -Force` **静默失败**（脚本级 `SilentlyContinue` 吞错误），
残留空目录骨架 `packages\vm-service\dist`；`cmd rmdir /s /q`、`[IO.Directory]::Delete` 同样失败。
⇒ 卸载删除的正解是**先确保进程真退出（查 cwd 持有者）**，不是换删除 API、更不是丢回收站。

**方法学教训（本轮踩到 3 次）**：`ps-run.sh` 载荷**含任何非 ASCII 字符即被门禁拒**
（`NON_ASCII_PAYLOAD`），**中文注释也算**。表现是「1.6s 就返回、零输出」，极易误读成
「脚本跑了但结论正常」。判定信号：总耗时 < 2s 而脚本明显该更久 ⇒ 先看有没有 `NON_ASCII_PAYLOAD`。
