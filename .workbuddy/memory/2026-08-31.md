## 远程一键部署分发链路修复（Task #41–#46 收尾）

**问题**：`setup.mjs --apply` 一键把本插件装到宿主机 + 远程 Windows VM，但远程产物跑不起来，两个根因：
1. 远程只收到 `dist`，`dist` 内 ESM 仍用裸包名 `from '@winvm/...'`，无 `node_modules/@winvm/*` → `ERR_MODULE_NOT_FOUND`。
2. 分发清单只发 `dist` + `package.json`，漏发 `psmod/`（54 能力 PS 实现）与 `contracts/schemas/` → self-test 报找不到 ps-bridge 脚本。

- `delivery/link-workspace.mjs`（新）：为「仅 dist」产物建 `node_modules/@winvm/<pkg>` → `packages/<pkg>` 的 Windows **junction 软链**（免管理员/免联网/幂等）；`planWorkspaceLinks()` 纯函数产出 create/skip-ok/skip-conflict。
- `install-vm.mjs`：依赖解析步骤 `--skip-install` 跳过 npm ci 后改走软链；新增 `--skip-links`；失败 fail-closed。
- `setup.mjs`：`packagePayloadPaths()` 排除法清单（排除 src/node_modules/tsconfig*，含 dist/psmod/schemas/package.json，不含 node_modules）。
- 12 包全为内部 `@winvm/*` 依赖 → junction 即可解析，远程免联网。
