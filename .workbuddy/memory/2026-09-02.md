## 真机终验执行 + 两处新 bug 修复（已 commit aca7d08）
- 远端 `codebuddy --version` = 2.143.0，硬依赖补齐。
- 首次 `setup.mjs --apply` 暴露两个 bug：
  1. **[BUILD] `spawn npm ENOENT`**：`run()` 在 Windows 上 `spawn('npm')` 找不到可执行体（npm 是 `npm.cmd` 批处理）。修复：`run()` 对 npm/npx/yarn/pnpm 在 win32 加 `shell:true`，其余命令（node/ssh/scp/tar/curl 真实 .exe）保持无 shell。
  2. **[VM self-test] `ps-bridge 未运行`**：远端 `install-vm.mjs` 第6步自检报 `PSBRIDGE_NOT_RUNNING`。用远端 Node 诊断脚本（`onStderr` 抓 stderr）定位根因——**`psmod/*.ps1` 含中文 + PS 子表达式但无 UTF-8 BOM**，中文 Windows 的 PS 5.1 对无 BOM .ps1 默认按 GBK 解码，把含 `$(...)` 的中文行误判「字符串缺少终止符」、ps-bridge 进程启动即退出。宿主 e2e 能过只是因宿主 PS 环境（pwsh7/UTF-8 代码页）碰巧解码正常。修复：**给 6 个 `psmod/*.ps1` 前置 UTF-8 BOM（efbbbf）**。
- 另有一次 VM 步骤 `Connection reset by <VM_TAILSCALE_IP> port 22`：SSH 瞬时重置（网络抖动，非代码问题），重试即过。
