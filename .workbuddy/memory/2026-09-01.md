## 关键事实（已对齐代码）
- bearer token 真实环境变量名 = `WINVM_BEARER_TOKEN`（非 `WINVM_TOKEN`）。
- SSH 认证：脚本直调系统 `ssh`，`.env` 无密码字段 → 只能密钥；密码在原生 Windows 下无法无人值守（`sshpass` 不随系统，`plink -pw` 不被调用）。
- 回环隧道下 Bearer 层免校验；仅非回环直连才强制 `tokenEnv`。
