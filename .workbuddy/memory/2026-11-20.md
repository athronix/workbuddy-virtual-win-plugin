## V1.4.36 → V1.4.37：host-only 语义从「加开关」到「分支顺序」

### V1.4.36 只修了一半

`9e0b267` 新增 `--host-only` + `planVmPhase`，让「VM 相位跳过」不再计入失败 —— 解决了**计数**。
但 `printVerification` 里 `if (vm)` 排在 `hostOnly` 之前，生产机上 `vm-conn.json` 恰好存在
⇒ `--apply --host-only` 仍会走进 VM 分支、去连 SSH，最后落 `else` 打出
**`[PASS] VM side checks (observed: skipped (dry-run))`** —— 在 `--apply` 场景下这句自相矛盾。

**教训：加开关 ≠ 开关生效。决策函数写对了，接线顺序错了照样打脸，而且打的是「最该看清的那一行」。**
`0c1bcaa` 把分支前移为 `if (hostOnly) / else if (vm)`，措辞改 `skipped (VM phase did not execute)`，
并加测试钉死分支顺序（`assert iHostOnly < iIfVm`）。

### v2.5.7 门禁踩的两个坑

1. **`--host-only` 子串假绿**：该字样同时出现在调用行、判据行（`HOSTONLY_NEW=... awk`）、
   诊断行（`grep -E`）。只查子串时**删掉调用处的开关仍能命中** ⇒ M60/M61 双 `[MISSED]`。
   改 `re.search(r'delivery/uninstall\.mjs\s+--apply\s+--host-only', body)` 锚定实际调用行后才
   `ALL_CAUGHT 61/61`。**门禁的全绿本身不算证据，突变反证才算。**
2. **awk 正则里的转义**：脚本写的是 `'\[PASS\] HOST'`（带反斜杠），按字面 `'[PASS] HOST'` 匹配
   永远失败 —— 首次跑就误报 `判据丢了 HOST 行`。

### v2.5.8（本轮）：只补排错表，代码零变更

V1.4.37 是**纯母项目侧**修复（分支顺序 + 措辞），skill 侧无需改代码。但排错表缺一条：
遇到 V1.4.36 的包会打 `skipped (dry-run)`，用户看到会误判「卸载没真跑」。
补上说明 + 判据一律只看 `HOST_PASS=11 / HOST_FAIL=0 / host_only_ack`，
并把该行标注「**别据此判断卸载没真跑**」。

## v2.5.9 零配置上手（用户口径：新机一条命令就够）

用户要求把「落包目录 / 问什么 / 口令怎么给 / 第一跑怎么做」全部**植入 skill**，
让新鸿蒙机上的使用者不必再读额外说明。落地为四个默认值/默认行为 + 一段文档 + 一条门禁。

### 改动（skill 仓 `99c4900` / tag v2.5.9）

| 项 | 改动点 | 为什么 |
|---|---|---|
| VM 地址 | `_common.sh:resolve_env` → `: "${VM_HOST:=172.16.100.2}"` | 原来默认空 ⇒ 新机首次**必停** `require_host`，等于强制用户回答一个我们有默认答案的问题 |
| 口令文件 | 文件存在时自动设 `WINVM_PASSWORD_FILE=$HOME/.winvm-pass` | 用户按文档写一次就长期生效，不用每次传参；**不存在则保持空值**，避免把空文件误判成空口令意图 |
| 默认无密码 | `deploy-1p-autokey.sh` 加 `WINVM_SSH_DEFAULT_EMPTY`（默认 1） | **修真实缺陷**：agent 无 tty，而口令来源只有 env/VM_PASSWORD/文件/tty 四种，全落空就 `return 1` ⇒ 1p 永远走不到，静默退化成「给用户一条管理员命令」，用户还不知道为什么要粘 |
| /tmp 禁令 | 新增 `vm_tmpdir()`（`${TMPDIR:-$HOME/wbtmp}`）+ 清掉 `legacy/preflight.sh` 最后一处裸 `/tmp` | 鸿蒙 `/tmp` 只读（`curl` 报 23），报错像网络问题，极难归因 |
| 文档 | `SKILL.md` 新增「零配置上手」 | 把「第一次裸跑 / 三种收尾行 / 只在三种情况问用户 / 有密码怎么给 / 无密码默认 / 临时目录」写成 agent 可照做的段落 |

### 坑

- **聚合仓默认 SSH key 不通**：必须 `GIT_SSH_COMMAND="ssh -i $HOME/.ssh/id_ed25519_github -o IdentitiesOnly=yes"`。
- **`raw.githubusercontent.com` 会偶发长时间无响应**：拉模板务必带 `--max-time 30 --retry 2`，
