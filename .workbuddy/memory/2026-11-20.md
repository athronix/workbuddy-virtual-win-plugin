### pid 方案 B 生产判据（全部为真）

**runDir 实际是 `C:\WinVMBridge\run`，不是 `C:\WinVMBridge\repo\run`。**
探错路径会得到 `RUNDIR_EXISTS=False` + 两个 MISSING，极易误判成「方案没生效」
（本次第一探就踩到）。`Kill-PidFile` 的 `$RunDirs` 两处都查，所以功能没受影响，
但手工取证必须两处都试。

```

ps-bridge.pid LINES=2 PID=9888 ALIVE=True NAME=powershell STARTTIME_DELTA=0
PORT_OWNER=3928   ← service.pid 正是 18443 占用者
```

卸载 DRY-RUN 确认走快路、不再全表扫描：
`[DRY] taskkill /T /F service node (pid file) PID 3928 (from pid file)`。
